# v1.0.5 - Lane-A v1.0 pre-execution blocker

This immutable release stops v1.0 before candidate invocation. The four-case
pool published in v1.0.4 is valid, but the pre-draw freeze did not bind an
execution driver or executable implementations for all required controls.
Because every comparison row is mandatory, implementing those components after
the draw would be a post-selection protocol change.

No model was invoked and no raw attempt was reserved. The global count remains
four consumed attempts and eight remaining. The disclosed v1.0 cases are not
reused as fresh evidence.

Smallest recovery condition: before any fresh draw, bind and case-free test one
complete execution package containing the driver, workspace construction,
custody, trajectory and authority audit, evaluator adapter, replay verifier,
and executable implementation and validation bytes for every frozen control.

This is a checkable pre-execution blocker, not a capability result and not
authorization for another protocol-building cycle.
